# Вопрос 1. Тема: Форматы JSON и CSV
  
**1. Что из перечисленного НЕ является допустимым типом данных в JSON?**
  
Варианты ответов:
1) Словарь
2) Строка
3) ✅ Функция
  
### ИИ анализ
Правильный ответ — «Функция». JSON — это текстовый формат для обмена данными, который поддерживает базовые типы: строки, числа, булевы значения, null, массивы и объекты. Функции, классы или другие исполняемые элементы не являются допустимыми типами данных в JSON, так как формат предназначен только для данных, а не для кода.  

# Вопрос 2. Тема: Форматы JSON и CSV
  
**2. Какой параметр позволяет улучшить читаемость JSON-файлов при записи?**
  
Варианты ответов:
1) newline
2) ✅ indent
3) formatter
  
### ИИ анализ
Правильный ответ — «indent». При записи JSON-файла с помощью функции `json.dump()` или `json.dumps()` параметр `indent` определяет количество пробелов для отступов, что форматирует вывод с вложенными структурами, делая его удобочитаемым для человека. Параметры `newline` и `formatter` не являются стандартными параметрами модуля `json` в Python для этой цели.  

# Вопрос 3. Тема: Форматы JSON и CSV
  
**3. Какой метод используется для записи данных в JSON-файл?**
  
Варианты ответов:
1) ❌ json.write()
2) json.save()
3) json.dump()
  
### ИИ анализ
Выбран неверный вариант. Правильный метод — `json.dump()`. Этот метод сериализует объект Python (например, словарь или список) в JSON-форматированную строку и записывает её в файловый объект. Методы `json.write()` и `json.save()` не существуют в стандартном модуле `json` Python.  

# Вопрос 4. Тема: Форматы JSON и CSV
  
**4. Какой метод используется для записи данных в CSV-файл?**
  
Варианты ответов:
1) csv.read()
2) csv.dump()
3) ✅ csv.writerows()
  
### ИИ анализ
Правильный ответ — `csv.writerows()`. После создания объекта writer с помощью `csv.writer()`, метод `writerows()` позволяет записать несколько строк (списков) данных в CSV-файл за один вызов. Метод `csv.read()` используется для чтения, а `csv.dump()` не является стандартным методом модуля `csv`.  

# Вопрос 5. Тема: Форматы JSON и CSV
  
**5. Какой из следующих форматов поддерживает вложенные структуры данных?**
  
Варианты ответов:
1) ✅ JSON
2) CSV
3) Оба
  
### ИИ анализ
Правильный ответ — «JSON». Формат JSON изначально поддерживает вложенные структуры, такие как объекты (словари) и массивы (списки) внутри других объектов или массивов. CSV — это плоский табличный формат, предназначенный для строк и столбцов; он не поддерживает вложенность данных в том же смысле, что и JSON.
