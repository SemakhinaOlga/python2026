# Вопрос 1. Блок 4. CSS: селекторы, каскад, специфичность, базовые стили
  
### Содержание и вопросы

- Как подключается CSS?
- Что такое селекторы по тегу и по классу?
- Почему класс предпочтительнее id для стилизации?
- Что такое каскад и почему “побеждает” одно правило?

### Материал (лаконично)

- `styles.css` это отдельный файл со стилями. Он подключается в `head`.
- Селекторы:
  - по тегу. Применяются ко всем элементам этого типа
  - по классу. Применяются только там, где ты добавил класс. Это удобнее для проекта
- Каскад это ситуация, когда несколько правил подходят к одному элементу. Тогда “побеждает” более конкретное правило.
- Специфичность в простом виде:
  - id обычно сильнее класса
  - класс сильнее тега
- Для обучения и для маленьких проектов лучше опираться на классы. Так проще поддерживать верстку.
  
Варианты ответов:
1) ✅ Прочитано
  
### ИИ анализ
Этот вопрос проверяет ознакомление с теоретическим материалом. Поскольку отмечен вариант "Прочитано", можно сделать вывод, что студент изучил предоставленные темы. Для успешного применения знаний на практике важно не только прочитать, но и понять принципы каскада и специфичности.

Варианты ответов:
1) Так не нужен `head`
2) Так отключаются отступы

# Вопрос 6. Что такое каскад в CSS простыми словами (когда несколько правил применяются к одному элементу)?
  
  
Варианты ответов:
1) Способ вставки картинок
2) Способ добавить мета-теги
3) ✅ Правила могут перекрывать друг друга
4) Способ рисовать таблицы
5) Список тегов в HTML
  
### ИИ анализ
Ответ верный. Каскад — это механизм CSS, который определяет, какое окончательное стилевое правило будет применено к элементу, когда на него претендует несколько правил. "Перекрытие" происходит на основе специфичности селекторов и порядка их объявления.  

# Вопрос 7. Какой селектор обычно “сильнее” по специфичности (имеет приор приоритет при применении стилей)?
  
  
Варианты ответов:
1) любой текст сильнее CSS
2) пробел сильнее селектора
3) ✅ id сильнее класса
4) тег сильнее id
5) комментарий сильнее правила
  
### ИИ анализ
Правильный ответ отмечен. В иерархии специфичности селектор по id (`#id`) имеет больший вес, чем селектор по классу (`.class`), который, в свою очередь, сильнее селектора по тегу. Это ключевое правило для понимания каскада.
