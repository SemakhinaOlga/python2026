# Вопрос 1. Блок 5. Box model и управление отступами
  
### Содержание и вопросы

- Что входит в box model?
- Чем `margin` отличается от `padding`?
- Зачем нужен `box-sizing: border-box`?
- Почему элемент “не влезает” в ширину?

### Материал (лаконично)

- У каждого блока есть “коробка”.
- `padding` это воздух внутри блока. Он отодвигает текст от края рамки.
- `margin` это расстояние снаружи блока. Он раздвигает блоки друг от друга.
- Если ты задаешь элементу ширину и добавляешь padding и рамку, без `border-box` элемент может стать шире, чем ты ожидал.
- `box-sizing: border-box` делает ширину предсказуемой. Padding и рамка входят в заданную ширину.
  
Варианты ответов:
1) ✅ Прочитано
  
### ИИ анализ
Этот вопрос проверяет ознакомление с теоретическим материалом. Поскольку отмечен вариант "Прочитано", можно сделать вывод, что студент изучил предоставленную информацию о box model. Для успешного применения знаний на практике важно не только прочитать, но и понять различия между margin, padding и принцип работы border-box.  

#  Вопрос 2. Практическое задание (Блок 5)
  
### Условия

Наведи порядок в отступах пошагово:

1. В `styles.css` включи `border-box` для всех элементов одним правилом.
2. Выбери один основной вертикальный отступ и используй его для секций.
3. Применяй этот отступ ко всем секциям одинаково.
4. Для карточек проектов:
   - добавь внутренний отступ
   - добавь рамку или фон
   - добавь скругление углов
5. Открой страницу и проверь:
   - текст не прилипает к краям
   - расстояния между секциями выглядят одинаково

Ограничения:

- Отступы должны быть согласованными. Не делай “случайные” значения для каждого элемента.

### Псевдокод решения

```text
IN CSS_FILE
  APPLY BORDER_BOX_TO_ALL

  FOR EACH SECTION_BLOCK
    SET OUTER_SPACING

  FOR EACH CARD_BLOCK
    SET INNER_SPACING
    SET BORDER_OR_BG
    SET CORNER_ROUNDING
END
```

### Если использовал ИИ, обязательные изменения вручную

- Перестрой отступы так, чтобы они задавались через 1-2 “основных” правила, а не через множество точечных.
- Добавь правило, которое улучшает поведение изображений в карточках (без фиксированной ширины).

---

**Вставь решение в комментарий ниже:**
  
### 🟢 Ответ
/* 1. Включаем border-box для всех элементов */  
*,  
*::before,  
*::after {  
  box-sizing: border-box;  
}  
  
/* 2. Основные отступы через универсальное правило для секций и их содержимого */  
/* Задаём переменную для основного отступа */  
:root {  
  --space-vertical: 40px;  
  --space-inner: 20px;  
}  
  
/* Универсальный внешние вертикальные отступы для секций */  
section {  
  margin-block: var(--space-vertical);  
  padding-inline: var(--space-inner); /* чтобы текст не прилипал к краям */  
}  
  
/* 3. Карточки проектов: внутренние отступы, оформление, скругление */  
.project-card {  
  padding: var(--space-inner);  
  background-color: #f9f9f9;  
  border-radius: 8px;  
}  
  
/* 4. Улучшение поведения изображений в карточках — img без фиксированной ширины, в пределах родителя */  
.project-card img {  
  max-width: 100%;  
  height: auto;  
  display: block;  
  border-radius: 6px; /* если нужно — можно добавить скругление */  
}  
  
### ИИ анализ
Отличное решение! Студент корректно применил `box-sizing: border-box` для всех элементов, использовал CSS-переменные для согласованности отступов и создал универсальные правила для секций и карточек. Правило для изображений (`max-width: 100%`) эффективно предотвращает выход картинки за границы родительского блока. Решение полностью соответствует условиям задания и демонстрирует хорошее понимание организации отступов.  

# Вопрос 3. Что такое `padding` в CSS простыми словами (отступ внутри блока)?
  
  
Варианты ответов:
1) Цвет рамки
2) Тип шрифта
3) Отступ между блоками
4) ✅ Отступ внутри блока
5) Ссылка на файл
  
### ИИ анализ
Правильный ответ выбран. `Padding` — это внутренний отступ элемента, который создает пространство между его содержимым (например, текстом) и границей (border) этого элемента. Это ключевая часть box model, которая влияет на внутренние размеры блока.  

# Вопрос 4. Что такое `margin` в CSS простыми словами (отступ снаружи блока)?
  
  
Варианты ответов:
1) Отступ внутри блока
2) Название секции
3) Размер картинки
4) Высота текста
5) ✅ Отступ снаружи блока
  
### ИИ анализ
Ответ верный. `Margin` определяет внешние отступы элемента, создавая пространство между этим элементом и соседними элементами на странице. В отличие от `padding`, `margin` находится за пределами границы (border) блока.  

# Вопрос 5. Для чего обычно используют свойство `box-sizing: border-box` в CSS?
  
  
Варианты ответов:
1) Чтобы заменить flexbox
2) ✅ Чтобы ширина была предсказуемой
3) Чтобы увеличить шрифт
4) Чтобы отключить фон
5) Чтобы скрыть ссылки
  
### ИИ анализ
Правильный ответ выбран. Свойство `box-sizing: border-box` изменяет модель расчета ширины и высоты элемента, включая `padding` и `border` в указанные размеры (`width` и `height`). Это делает верстку более предсказуемой и удобной, так как добавление отступов и рамок не увеличивает общие габариты блока.  

# Вопрос 6. Почему на странице может появиться горизонтальная полоса прокрутки из-за размеров элементов?
  
  
Варианты ответов:
1) `title` слишком длинный
2) ✅ Элемент стал шире экрана
3) `footer` пустой
4) `meta` не тот
5) `head` слишком большой
  
### ИИ анализ
Ответ верный. Горизонтальная полоса прокрутки чаще всего появляется, когда общая ширина содержимого страницы (ширина какого-либо элемента, сумма отступов и т.д.) превышает ширину области просмотра (viewport). Использование `box-sizing: border-box` и правил вроде `max-width: 100%` для изображений помогает предотвратить эту проблему.  

# Вопрос 7. Что значит “согласованные отступы” при работе с CSS?
  
  
Варианты ответов:
1) Каждый блок со своим числом
2) ✅ Одни и те же правила повторяются
3) Отступов нет нигде
4) Отступы только у ссылок
5) Отступы только у картинок
  
### ИИ анализ
Правильный ответ выбран. Согласованные отступы подразумевают использование единой системы значений (например, через CSS-переменные) для схожих элементов на странице. Это создает визуальную гармонию, делает интерфейс аккуратным и упрощает поддержку кода, так как изменения вносятся в одном месте.  

# Вопрос 8. Что из перечисленного относится к CSS box model (модель блока)?
  
  
Варианты ответов:
1) hover, active, visited, focus
2) ✅ margin, border, padding, content
3) ul, ol, li, a
4) jpg, png, svg, gif
5) title, meta, link, script
  
### ИИ анализ
Ответ верный. CSS Box Model — это фундаментальная концепция, описывающая прямоугольные блоки, генерируемые для элементов. Она включает в себя, начиная изнутри: содержимое (content), внутренний отступ (padding), границу (border) и внешний отступ (margin).  

# Вопрос 9. Какое CSS-правило для изображений в карточках помогает избежать проблем с шириной блока?
  
  
Варианты ответов:
1) Картинка отключает рамку
2) Картинка становится ссылкой
3) Картинка добавляет заголовок
4) Картинка меняет язык страницы
5) ✅ Картинка не ломает ширину блока
  
### ИИ анализ
Правильный ответ выбран. Чтобы изображение не выходило за пределы родительского блока и не создавало горизонтальную прокрутку, часто используют правило `max-width: 100%`. Оно ограничивает максимальную ширину изображения шириной его контейнера, при этом сохраняя пропорции, если также задано `height: auto`.
