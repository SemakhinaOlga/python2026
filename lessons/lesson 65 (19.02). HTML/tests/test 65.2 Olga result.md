# Вопрос 1. Блок 3. Текстовый контент, ссылки, списки, изображения
  
### Содержание и вопросы

- Как сделать ссылку и какие бывают `href`?
- Чем `ul` отличается от `ol`?
- Зачем нужен `alt` у изображения?
- Как структурировать “карточку” проекта только HTML-ом?

### Материал (лаконично)

- Ссылка это тег `a`. Внутри должен быть текст, по которому понятно, куда ведет ссылка.
- `href` может быть:
  - обычным адресом сайта
  - якорем внутри страницы
  - `mailto:` для письма
- Списки:
  - `ul` когда порядок не важен, например “навыки”
  - `ol` когда это шаги, порядок важен
- Картинка это `img`. `alt` обязателен. Если картинка не загрузится, текст `alt` подскажет, что там должно быть.
- “Карточка” проекта это просто блок. Обычно внутри: заголовок, текст, ссылка.
  
Варианты ответов:
1) ✅ Прочитано
  
### ИИ анализ
Этот вопрос проверяет ознакомление с теоретическим материалом.  Отметка "Прочитано" означает, что студент просмотрел предоставленные материалы.  Для лучшего усвоения рекомендуется не просто читать, но и сразу пробовать применять эти концепции на практике, например, создавая простые HTML-страницы.

# Вопрос 3. Какой HTML-тег используется для создания обычной ссылки на другую страницу?
  
  
Варианты ответов:
1) `span`
2) `p`
3) `div`
4) `img`
5) ✅ `a`
  
### ИИ анализ
Правильный ответ — тег `<a>`.  Именно этот тег (anchor — якорь) создаёт гиперссылки с помощью обязательного атрибута `href`, который содержит адрес целевой страницы.  Остальные варианты (`span`, `p`, `div`, `img`) служат для других целей: разметки текста, создания блоков или вставки изображений, но не для навигации.  

# Вопрос 4. Какой тип списка лучше подходит для раздела “навыки”, где порядок элементов не имеет значения?
  
  
Варианты ответов:
1) ✅ `ul`
2) `ol`
3) `form`
4) `nav`
5) `table`
  
### ИИ анализ
Для перечня навыков, где порядок не важен, семантически правильным выбором является неупорядоченный список `<ul>`.  Он отображает элементы с маркерами, подчёркивая их равнозначность.  Упорядоченный список `<ol>` использовался бы для шагов или рейтингов, где важен номер позиции.  Остальные теги не предназначены для создания списков.  

# Вопрос 5. Зачем нужен атрибут `alt` у тега изображения `img`?
  
  
Варианты ответов:
1) Для выравнивания текста
2) Для подключения CSS
3) Для создания отступов
4) ✅ Для текстового описания картинки
5) Для изменения размера картинки
  
### ИИ анализ
Атрибут `alt` предоставляет альтернативный текстовый контент для изображения.  Это критически важно для доступности: скринридеры зачитывают этот текст для незрячих пользователей.  Также `alt` отображается, если изображение не загрузилось, помогая понять, что должно было быть на картинке.  Остальные функции выполняются с помощью CSS или других атрибутов.  

# Вопрос 6. Какое значение атрибута `href` используется для создания ссылки, которая открывает почтовую программу?
  
  
Варианты ответов:
1) `css:`
2) `http:`
3) `file:`
4) ✅ `mailto:`
5) `ftp:`
  
### ИИ анализ
Правильный префикс — `mailto:`.  Он указывает браузеру, что ссылка ведёт на адрес электронной почты, и при клике обычно открывается почтовый клиент для создания нового письма указанному получателю.  Остальные протоколы (`http:`, `file:`, `ftp:`) используются для доступа к веб-страницам, локальным файлам или файловым серверам соответственно.  

# Вопрос 7. Какие элементы обычно должны быть внутри “карточки проекта” на странице-визитке?
  
  
Варианты ответов:
1) Только картинка без текста
2) Только таблица с данными
3) Только `meta` теги
4) Только `script` код
5) ✅ Заголовок, текст, ссылка
  
### ИИ анализ
Типичная карточка проекта — это самодостаточный блок информации.  Заголовок (`<h3>`) называет проект, краткий текст описывает его суть, а ссылка (`<a>`) ведёт на подробную страницу или демо.  Такой набор даёт пользователю полное представление и возможность углубиться.  Остальные варианты не формируют законченную информационную единицу.  

# Вопрос 8. Что нужно проверить после добавления ссылок и изображений на страницу?
  
  
Варианты ответов:
1) ✅ Что все ссылки имеют `href`
2) Что нет `main`
3) Что нет `section`
4) Что `head` пустой
5) Что нет `footer`
  
### ИИ анализ
Ключевая проверка — наличие атрибута `href` у всех тегов `<a>`.  Без `href` ссылка не будет работать и станет бесполезной для пользователя.  Также важно проверить наличие атрибута `alt` у изображений.  Остальные пункты не относятся к проверке функциональности ссылок и изображений, а теги `main`, `section` и `footer` являются валидными и полезными элементами структуры.  

# Вопрос 9. Какое главное требование к тексту внутри ссылки для удобства пользователей?
  
  
Варианты ответов:
1) Чтобы он был на одной букве
2) ✅ Чтобы он был понятным
3) Чтобы он был скрыт стилями
4) Чтобы он был только цифрами
5) Чтобы он был пустым
  
### ИИ анализ
Текст ссылки (анкор) должен быть понятным и самодостаточным, чтобы пользователь мог предсказать, куда он попадёт после клика.  Это важно для навигации, доступности (скринридеры зачитывают ссылки) и SEO.  Неочевидные анкоры вроде "кликните здесь" или пустые ссылки ухудшают пользовательский опыт.
