# Вопрос 37. Тема 6: Основы асинхронного программирования

Варианты ответов:

3) Для рисования графики
4) ✅ Для задач с ожиданием

Для задач, требующих интенсивных вычислений (CPU-bound), она не даёт преимуществ и может даже замедлить работу.  Её сила — в управлении множеством операций ввода-вывода без создания множества потоков.

# Вопрос 38. Тема 6: Основы асинхронного программирования

# Вопрос 39. Тема 6: Основы асинхронного программирования

Варианты ответов:

3) Завершает программу
4) Создает список

### ИИ анализ
Ключевое слово `await` приостанавливает выполнение текущей корутины до тех пор, пока переданная ему асинхронная операция (другая корутина, задача, future) не завершится.  Это позволяет программе в это время выполнять другие задачи, обеспечивая неблокирующее ожидание.  `await` можно использовать только внутри функции, объявленной с помощью `async def`.
